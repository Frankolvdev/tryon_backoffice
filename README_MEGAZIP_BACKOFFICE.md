# MegaZIP 2 — BackOffice comercial

- Cupones administrados por el backend; se elimina la dependencia visual de sincronización Stripe.
- Planes y paquetes usan etiquetas sencillas para explicar la ganancia y el beneficio.
- La vista Finanzas muestra un recibo comprensible y el detalle por bolsa de tokens.

Aplicación:
Remove-Item -Recurse -Force .next -ErrorAction SilentlyContinue
npm run build
npm run dev
