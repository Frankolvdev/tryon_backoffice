# MegaZIP 2B — BackOffice Caja y Bolsas

## Aplicar
1. Descomprimir sobre la raíz del BackOffice.
2. Eliminar `.next`.
3. Ejecutar `npm run build` y `npm run dev`.

## Ruta
`/dashboard/finances/cashbox`

## Incluye
- Caja disponible, protegida, bloqueada y retiros.
- Registro de retiros con bloqueo por saldo disponible.
- Configuración de caducidad en días.
- Tabla de bolsas y detalle económico.
- Generaciones financiadas por cada bolsa.
- Conciliación con Stripe y reembolso cuando la bolsa es elegible.
