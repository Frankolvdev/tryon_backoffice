# Fix UI: descuentos porcentuales sobre ganancia

- Pricing muestra únicamente la ganancia segura global y la regla limitante.
- Planes y paquetes incluyen Descuento deseado sobre la ganancia (%).
- Cada formulario muestra ganancia segura, descontada, restante y pérdida potencial.
- No permite guardar porcentajes mayores a 100%.
- Cupones quedan exclusivamente porcentuales; se eliminan importe fijo y moneda fija.
- El backend sigue siendo la autoridad final y valida descuentos combinados.
