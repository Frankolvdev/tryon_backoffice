# Body Proportion Generator V2 — BackOffice

Vista: `/dashboard/tools-generation/body-proportions`

- 48 presets base aparecen automáticamente para Mujer.
- Agrupados en Low Fat / Medium Fat / High Fat.
- Cada grupo contiene 4 filas Ass x 4 columnas Breast.
- Preview y valores editables por categoría.
- Generar/regenerar categoría, grupo completo o pendientes.
- Reglas avanzadas colapsables.
- Selector de storage Auto / Local / Amazon S3 / Cloudflare R2.
- Creador de preset intermedio 50% entre dos presets existentes.
- Hombre queda preparado, sin inicialización automática mientras no exista workflow.
